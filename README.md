## About

I'm a **Software Engineer** who builds full-stack web products, from the database and API to the user interface. **.NET Core is my main stack**, paired with Angular on the frontend, and I focus on clean architecture, secure APIs, and code that stays easy to maintain.

I'm adaptable: when a project calls for a different stack, I learn it and use it, so the technology never gets in the way of delivering the right solution.
